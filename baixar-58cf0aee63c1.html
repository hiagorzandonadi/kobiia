Obrigado pela compra! 💚

Seu Kobi é seu para sempre, com as atualizações incluídas. Escolha o seu sistema:

⬇ Baixar para Windowsrecomendado Versão portátil (sem instalar)
Windows 10 e 11, 64 bits. Se aparecer "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo. Isso acontece com apps novos.
⬇ Mac com chip Apple (M1, M2, M3, M4, M5) ⬇ Mac Intel
Não sabe qual é o seu? Menu → Sobre Este Mac: se aparecer "Chip Apple M…", é o primeiro. Abra o .dmg, arraste o Kobi para Aplicativos e, na primeira vez, clique nele com o botão direito → Abrir. Se o Mac bloquear: Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.
⬇ AppImage (qualquer distribuição) ⬇ Ubuntu / Debian / Mint / Zorin (.deb)
AppImage: clique com o botão direito → Propriedades → marque Permitir executar e abra. O .deb instala com dois cliques.

🔑 Como ativar

Na primeira vez que abrir, o Kobi pede o e-mail que você usou na compra. É só digitar e clicar em Ativar (precisa de internet nessa hora). Se acabou de pagar e não funcionar, espere 1 minuto e tente de novo.
